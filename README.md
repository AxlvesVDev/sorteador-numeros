# 🎲 Sorteador de Números

Um projeto simples em **HTML, CSS e JavaScript** que permite ao usuário sortear números aleatórios dentro de um intervalo definido. Feito para praticar conceitos intermediários de JavaScript, como eventos, funções, DOM e animações básicas.

## 🚀 Funcionalidades

- O usuário define:
  - Quantos números quer sortear
  - O intervalo mínimo e máximo
  - Se os números podem ou não se repetir
- Os números sorteados aparecem um por um, com animação.

## 🧪 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (sem bibliotecas ou frameworks)
